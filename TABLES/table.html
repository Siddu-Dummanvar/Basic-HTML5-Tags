Table : The table provides highly effective way of presenting may kind of information

        * A table is the matrix of cell
        * Table tag is used to display the data in the tabular form i.e rows & columns

Some tags are used inside table

  • <table>:It defines the table
  • <th>:It defines heading of the table
  • <tr>:It defines rows in the table
  • <td>:It defines table data in the table
